# Módulo 2 — Comandos Essenciais

## Comandos principais

| Comando | O que faz |
|---|---|
| `/help` | Lista todos os comandos disponíveis |
| `/status` | Mostra o estado atual da sessão |
| `/doctor` | Verifica se o ambiente está configurado corretamente |
| `/init` | Cria um CLAUDE.md inicial no projeto |
| `/clear` | Limpa o histórico da conversa atual |
| `/compact` | Resume a conversa para liberar espaço de contexto |
| `/cost` | Mostra quanto de contexto você usou |
| `/permissions` | Mostra e gerencia permissões de ferramentas |
| `/model` | Troca o modelo (Sonnet, Opus, Haiku) |
| `/config` | Abre as configurações do Claude Code |

## Dicas de uso
- Use `/compact` quando a conversa estiver longa — evita perda de contexto
- Use `/cost` para monitorar uso se você tiver limite de tokens
- Use `/clear` para começar uma conversa limpa sem perder as configurações
