# Módulo 1 — Mentalidade e Fluxo de Trabalho

## O que o Claude Code faz melhor
- Editar e criar arquivos no seu computador
- Executar comandos no terminal
- Trabalhar em projetos com múltiplos arquivos
- Lembrar contexto do projeto via CLAUDE.md

## Quando usar cada ferramenta
| Ferramenta | Use quando... |
|---|---|
| Claude Code | Trabalhar em projetos, arquivos, automações |
| ChatGPT / Gemini | Pesquisar, rascunhar ideias, perguntas gerais |
| NotebookLM | Analisar documentos longos, PDFs |

## Como pedir tarefas
- **Pequena:** direto ao ponto — "crie um arquivo chamado x"
- **Média:** dê contexto — "esse projeto faz X, quero adicionar Y"
- **Grande:** peça um plano antes — "me mostre os passos antes de executar"

## Como revisar o que o Claude fez
- Leia o diff (resumo das mudanças) antes de aceitar
- Pergunte "o que você mudou e por quê?" se não ficou claro
- Use /undo se quiser desfazer

## Como evitar bagunça
- Peça uma coisa por vez
- Se o Claude sair do escopo, interrompa e redirecione
- Use CLAUDE.md para deixar regras claras (veremos no Módulo 3)

## Exercício
Abra o Claude Code e peça algo pequeno: "crie um arquivo chamado teste.txt com o texto olá mundo". Depois leia o que ele fez antes de aceitar.
