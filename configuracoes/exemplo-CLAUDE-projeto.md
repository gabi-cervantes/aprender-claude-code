# Exemplo de CLAUDE.md de Projeto (.claude/CLAUDE.md)

Este arquivo fica dentro do projeto e define regras específicas para aquele contexto.
Adapte para o seu projeto e salve em `.claude/CLAUDE.md` dentro da pasta do projeto.

## Regras para Claude

### Proteção de arquivos
- Nunca edite arquivos em pastas de sistema sem perguntar
- Nunca apague arquivos sem confirmar explicitamente
- Nunca crie arquivos novos fora das pastas esperadas sem avisar

### Comportamento antes de agir
- Antes de rodar qualquer tarefa complexa, explique o que vai acontecer
- Se uma tarefa tiver mais de 3 passos, liste os passos antes de começar
- Se encontrar ambiguidade, pergunte — não assuma

### Escopo
- Não refatore código que não foi pedido
- Não adicione funcionalidades além do que foi solicitado
- Foque em uma coisa por vez

### Comunicação
- Sempre responda em português
- Se algo der errado, explique o erro em linguagem simples antes de sugerir solução
