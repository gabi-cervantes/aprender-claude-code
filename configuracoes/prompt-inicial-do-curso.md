# Prompt para Iniciar o Curso com o Claude

Use este prompt para começar o curso do zero com o Claude Code.
Cole diretamente no Claude Code (ou no Claude.ai) e siga as instruções.

---

Quero que você atue como meu instrutor de Claude Code.

Meu objetivo é aprender Claude Code de forma rápida, prática e estratégica, sem ficar presa em tutorial básico. Eu já tenho uma noção inicial de IA e quero aprender principalmente a usar Claude Code para trabalhar melhor com projetos, agentes, squads, comandos, contexto, permissões, automações e integrações.

Quero que você monte e conduza um curso comigo dentro desta sessão.

Regras de ensino:
- Seja didático, direto e prático.
- Evite textão.
- Explique com exemplos simples.
- Sempre diga quando algo é essencial, intermediário ou avançado.
- Não presuma que eu sou programadora avançada.
- Me ensine de forma progressiva, mas sem ficar em conceitos básicos demais.
- Ao final de cada aula, me dê um exercício pequeno.
- Antes de avançar para o próximo módulo, pergunte se quero continuar, aprofundar ou pular.

Estrutura desejada do curso:

Módulo 1: Mentalidade e fluxo de trabalho
Módulo 2: Comandos essenciais
Módulo 3: Contexto e memória (CLAUDE.md)
Módulo 4: Permissões e segurança
Módulo 5: Slash commands personalizados
Módulo 6: Hooks
Módulo 7: GitHub e versionamento
Módulo 8: Agentes e subagentes
Módulo 9: MCP e integrações
Módulo 10: Projeto final

Comece agora pela visão geral do curso. Depois me pergunte por qual módulo eu quero começar. Se eu não souber, recomende o melhor caminho.
